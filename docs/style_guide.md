  # Chapter Title
  ## Section Title
  ### Subsection Title

-No sub-level should exist beyond three levels

-All headings have their own lines with a carriage return after each heading
-One should take the user-prompt for a main heading but use the content to rewrite the prompt as a heading:
1. Only do this for each markdown's main heading not subsection
2. Maintain sub-sections as per the original response
3. Make the heading reflect the whole markdown content
-Each chapter file must have exactly one # heading (the chapter title). All other headings use ## or ###

-For seriation use bullet points, but if the text is longer just use italicised headings
-For tables before the table place: Table X. HEADING, where X is the table number
-Favour free text over seriated lists, use seriation where clarity and distinction are required
-Use the structure and heading levels consistently and coherently
-Use markdown heading levels (#, ##, ###) to indicate heading hierarchy
