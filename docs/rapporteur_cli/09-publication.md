# Publication

Stage 11 (`PublishStage`) converts the enriched Markdown chapters into a typeset PDF via Sphinx and LaTeX.

## Build Pipeline

```{mermaid}
flowchart LR
    CH["chapters/*.md"] --> NORM["Normalise headings\nStrip Mermaid\nDemote extras"]
    NORM --> SRC["_sphinx_src/\n(cleaned copies)"]
    SRC --> CONF["Generate conf.py\n+ index.md"]
    CONF --> SPH["sphinx-build\n-M latexpdf"]
    SPH --> PDF["project-slug.pdf"]
```

## Source Preparation

The stage copies all chapter files to `_sphinx_src/` and applies several transformations:

### Heading Normalisation

- Only the **first** `#` heading in each chapter is kept as-is. Additional `#` headings are demoted to `##` so that Sphinx treats each file as a single chapter.
- Baked numeric prefixes (`1.2.3 Section Title`) are stripped — Sphinx auto-numbers sections via `secnumdepth=2`.

### Mermaid Stripping

Mermaid code blocks are replaced with a plain-text note (`*[Diagram omitted — see HTML build]*`) because the LaTeX toolchain runs headless without Chrome/.

### Footer Removal

Trailing `---` / `*Generated by Rapporteur CLI*` footers are stripped from every chapter.

### Metadata Removal

Leading blockquotes (duplicate abstracts) and `**Date:**` / `**Subject:**` metadata lines are removed.

### Image Linking

The stage symlinks (or copies) `build_dir/kaliya/` into `_sphinx_src/` so that relative image paths resolve correctly during the LaTeX build.

## Sphinx Configuration

The stage generates `_sphinx_src/conf.py` with:

| Setting | Value |
|---------|-------|
| Parser | MyST (Markdown → reStructuredText bridge) |
| Extensions | `myst_parser`, colon-fence, deflist |
| LaTeX engine | XeTeX (`xelatex`) |
| Body font | Palatino |
| Heading font | Helvetica |
| Code font | TeX Gyre Cursor |
| Line spacing | 1.5× |
| Paragraph skip | 0.6 em + 0.2 em stretch |
| Margins | 2.5 cm (all sides) |
| Section numbering | Chapters + sections (depth 2) |
| Figure numbering | Off |

## TOC Generation

A MyST `index.md` is generated with a `toctree` directive listing all chapter stems in manifest order:

```markdown
# Publication Title

```{toctree}
:maxdepth: 2
:caption: Chapters

00-introduction
01-chapter-slug
...
NN-conclusion
```
```

## Build Invocation

```bash
sphinx-build -M latexpdf _sphinx_src _build -q
```

Timeout: **600 seconds**. The build produces `_build/latex/{slug}.pdf`.

### Partial-Success Handling

If `sphinx-build` exits with a non-zero code but the PDF file exists (a known `latexmk` edge case), the stage logs a warning and continues. Only a genuinely missing PDF is treated as a fatal error.

## Post-Build

1. Copy `_build/latex/{slug}.pdf` → `build_dir/{slug}.pdf`.
2. Extract page count via `pdfinfo` (if available on the system).
3. Record in the manifest: PDF path, size in bytes, page count, word count, and timestamp.

## Inputs & Outputs

| Direction | Artefact |
|-----------|----------|
| In | `build_dir/chapters/manifest.json` |
| In | `build_dir/chapters/NN-*.md` |
| In | `build_dir/kaliya/images/*.jpeg` (optional) |
| Out | `build_dir/_sphinx_src/` (temporary) |
| Out | `build_dir/_build/latex/{slug}.pdf` |
| Out | `build_dir/{slug}.pdf` (final) |
